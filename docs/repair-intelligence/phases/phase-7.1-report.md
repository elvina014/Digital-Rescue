## Brad 확인·추가로 필요한 것

1. **시험 인쇄로 위치 맞추기 (필수).** 측정값 합계가 A4와 맞지 않는다:
   가로 6.5 + 47×4 + 2×3 + 6.5 = **207 mm** (A4 210), 세로 14.8 + 26.9×10 + 12 = **295.8 mm** (A4 297).
   스캔 배율 오차일 수 있다. 확인 순서:
   1. 폼텍 모드에서 '칸 테두리도 인쇄'를 켜고 **일반 A4 용지**에 인쇄한다 (배율 100%, 여백 없음).
   2. 라벨지와 겹쳐 빛에 비춰 본다.
   3. 오른쪽 끝 칸이 어긋나면 **가로 간격**을 조정한다 (예: 3 mm면 좌우 6.5 mm로 210 mm가 맞음).
      전체가 밀렸으면 왼쪽·위쪽 여백을 조정한다.
   4. 맞춘 값을 알려 주면 기본값으로 반영한다. 지금은 PC별 브라우저에만 저장된다.
2. **폼텍 프로그램 PNG 크기 확인.** 칸에 47 × 26.9 mm로 딱 맞게 들어가는지 확인한다. 프로그램이 DPI를 무시하면 '칸에 맞춤'으로 넣으면 된다 (가로세로 비율이 같음).
3. **QR 판독 확인.** 19 mm QR을 인쇄해 휴대폰·USB 스캐너로 읽히는지 본다. 안 읽히면 `labelLayout.ts`의 `LABEL_QR_MM`만 키우면 된다.
4. **브라우저 인쇄 설정.** 인쇄 창에서 대상 프린터, 용지 A4, 여백 '없음', 배율 '기본값/100%'를 확인한다. 머리글·바닥글을 끄고, 배경 그래픽은 꺼도 된다.
5. (선택) 폼텍 모드에는 라벨별 PNG 버튼이 없다 (전체 저장만 가능). 한 장만 필요하면 감열 모드로 바꿔 `PNG 저장`을 쓴다.

## 위험·참고

- 프린터 급지 오차(±0.5~1 mm)는 남는다. 라벨 안쪽 여백 1.5 mm가 흡수한다.
- 이미 사용한 칸 표시는 저장하지 않는다 (용지마다 다르므로 페이지를 열 때마다 새로 표시).
- 여러 PNG를 저장할 때 브라우저가 처음 한 번 '여러 파일 다운로드' 허용을 묻는다.
